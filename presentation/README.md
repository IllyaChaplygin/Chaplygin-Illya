# Постачальники снеків — презентація собівартості

`Постачальники_снеків_собівартість.pptx` — 27 слайдів, 16:9, для відділу маркетингу
та акаунт-менеджерів.

## Що всередині

| Слайди | Зміст |
|---|---|
| 1–4 | Титул, огляд 5 постачальників, методологія розрахунку собівартості, 4 сценарії логістики |
| 5–7 | Singha Kameda — профіль, 2 картки товарів, таблиця собівартості |
| 8–10 | Thai-Nichi — профіль, 2 картки товарів, таблиця |
| 11–16 | TMK / KOKIRI — профіль, 10 карток, таблиці |
| 17–23 | HanJin / ZEK — профіль, 14 карток, таблиці |
| 24 | Nature Best / KoriKo — асортимент без розрахованої собівартості |
| 25–27 | Зведений рейтинг 28 SKU, висновки, джерела |

На кожній картці товару: фото, назва, короткий опис, фасовка, ціна FOB і собівартість
одиниці у **$ та ₴** за сценарієм «40′ контейнер». Повні цифри за всіма чотирма
сценаріями — у таблицях після карток.

## Вхідні дані

* **SelfCost.xlsx** — собівартість: колонки `ИТОГО С/С, € ед. Товара` та
  `ИТОГО С/С, UAH ед. Товара` на вкладках `SINGHA KAMEDA - Retail`,
  `Thai-Nichi - Retail`, `TMK Thailand Co., Ltd -Retail`, `ZEK -Retail`.
  Кожна вкладка містить чотири блоки — 20′, 40′, збірний 17 м³, збірний 34 м³.
  Вкладка `Koriko` порожня.
* **Snacks. Price Comparison.xlsx** — фото товарів, ваги, фасовки, терміни
  придатності, ціни FOB.

### Прийняті припущення

* Підсумкова колонка собівартості у SelfCost підписана «€», але вхідні ціни — FOB
  у доларах і перерахунку в євро в розрахунку немає, тому показник наведено як `$`.
* Гривневі суми взято з файлу без перерахунку (у розрахунку курс 45–49 ₴ за $).
* ПДВ 20% включено в підсумкову собівартість.
* Смаки на фото лінійки KOKIRI Wow розібрані за кольоровим кодуванням бренду:
  зелений — Original, червоний — Spicy, фіолетовий — Squid.
* Фото `ZEK Sandwich Seaweed Meat Floss 25 г` у вихідному файлі дзеркальне —
  у деці відображено коректно.

## Перезбирання

```bash
pip install python-pptx openpyxl Pillow
python3 src/deck/build.py          # -> Постачальники_снеків_собівартість.pptx
```

`src/data.json` — собівартість, витягнута з SelfCost.xlsx (`src/extract.py`).
`src/photo/` — підготовлені фото (`src/prep_images.py`: обрізка полів, прибирання
чорного фону, нарізка лінійок на окремі смаки).
Обидва скрипти чекають вихідні xlsx за шляхами, вказаними в їхніх заголовках —
онови їх, якщо файли лежать деінде.

`src/render.py FILE.pptx` рендерить слайди у PNG через LibreOffice для візуальної
перевірки верстки.
